# File Transfer Protocol (FTP) Server Lab

## 📌 Overview

This project demonstrates a basic FTP (File Transfer Protocol) server lab created for networking practice. The purpose is to understand how a client connects to an FTP server and transfers files over a network.

## 🎯 Objectives

* Understand the basics of FTP.
* Learn how an FTP client communicates with an FTP server.
* Practice file uploading and downloading.
* Understand client-server communication in a network environment.

## 🖥️ Lab Topology

**FTP Client ↔ FTP Server**

The client connects to the FTP server over the network to access and transfer files.

## 🛠️ Technologies Used

* FTP (File Transfer Protocol)
* FTP Client
* FTP Server
* TCP/IP Networking

## 🧪 Lab Tasks

1. Configure a basic FTP server.
2. Establish a connection between the FTP client and server.
3. Test FTP connectivity.
4. Upload a file from the client to the server.
5. Download a file from the server to the client.
6. Verify that file transfers work correctly.

## 📚 What I Learned

* Basic FTP server configuration.
* Client-server communication.
* File transfer over a network.
* Fundamental networking troubleshooting.

## 🔐 Security Note

Traditional FTP does not encrypt usernames, passwords, or transferred data. For real-world environments, use a secure alternative such as SFTP or properly configured FTPS.
